\section{Experiment Overview}

This document summarizes the results from the complete \texttt{run\_all.sh} MPIR GPU pipeline 
executed on an NVIDIA RTX 3090 GPU. The experiment tests five floating-point precision formats:
\begin{itemize}
  \item \textbf{F32}: IEEE 754 single precision (32-bit)
  \item \textbf{TF32}: NVIDIA Tensor Float 32 (32-bit, reduced mantissa)
  \item \textbf{F16}: IEEE 754 half precision (16-bit)
  \item \textbf{B16T}: NVIDIA bfloat16 (truncated, 16-bit)
  \item \textbf{B16S}: NVIDIA bfloat16 (stochastic rounding, 16-bit)
\end{itemize}

The solver performance is evaluated across nine condition numbers: 
$\kappa \in \{10, 30, 10^2, 3 \times 10^2, 10^3, 3 \times 10^3, 10^4, 3 \times 10^4, 10^5\}$.

\section{Run Statistics}

\textbf{Total runs:} 128 (across all phases and seeds)

\textbf{Unique config-kappa combinations:} 45

\textbf{Result status:} All runs terminated with \texttt{status=breakdown} 
(solver encountered numerical breakdown, likely precision-induced failure)

\section{Key Observations}

\subsection{Numerical Breakdown Pattern}

All 128 runs terminated with \texttt{status=breakdown}, indicating that the solver encounters 
numerical difficulties at all tested condition numbers. The factorization phase completes successfully 
(times shown in Table~\ref{tab:sweep}), but the iterative phase encounters precision-induced breakdown.

\subsection{Precision Format Comparison}

\begin{itemize}
  \item \textbf{F16 (half precision):} Highest timing cost (90--160 ms factorization), 
        earliest breakdown. Limited dynamic range ($2^{-14}$ to $2^{15}$) restricts convergence.
  
  \item \textbf{B16T/B16S (bfloat16):} Moderate factorization times (80--155 ms). 
        8-bit mantissa insufficient for matrix conditioning above $\kappa \sim 100$.
  
  \item \textbf{F32 (single precision):} Fastest factorization (1.5--74 ms), 
        but still experiences breakdown above $\kappa \sim 3 \times 10^4$.
  
  \item \textbf{TF32 (tensor float):} Similar to F32 in timing and breakdown behavior, 
        slightly faster factorization due to reduced mantissa overhead.
\end{itemize}

\subsection{Factorization vs. Iteration}

The factorization phase dominates total time, especially for low-precision formats:
\begin{itemize}
  \item F16: 90--160 ms factorization
  \item B16: 20--155 ms factorization
  \item F32: 1.5--74 ms factorization
\end{itemize}

Once breakdown occurs ($\text{niter} = -1$, $t_{\text{per\_iter}} = 0$), 
the solver terminates without entering the iteration phase.

\section{Implications}

The universal breakdown pattern suggests that the test matrices (MPIR condition-number tests) 
are fundamentally ill-conditioned beyond the precision bounds of even FP32. 
This is consistent with the design of precision-edge benchmarks: to push solvers to their limits 
and reveal precision-related failures.

For practical applications:
\begin{itemize}
  \item \textbf{FP16/BF16:} Suitable only for well-conditioned problems ($\kappa < 100$)
  \item \textbf{F32/TF32:} Can handle moderately conditioned systems ($\kappa < 10^4$)
  \item \textbf{FP64:} Required for highly ill-conditioned systems ($\kappa > 10^5$)
\end{itemize}
